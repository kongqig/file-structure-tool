# file-structure-tool

轻量级文件夹结构扫描与展示工具，支持命令行和图形界面两种模式。递归扫描指定目录，以路径列表或树形缩进格式展示文件与文件夹结构，并可导出为文本文件。

## 功能特性

- **双模式运行**：无参数启动 GUI 图形界面，指定路径则进入命令行模式
- **递归扫描**：深度优先遍历目录，自动检测并跳过循环链接
- **路径样式输出**：支持四种路径前缀格式（文件夹名开头、点开头、无前缀、绝对路径）
- **树形结构输出**：可自定义缩进字符与缩进长度，直观展示层级关系
- **统计信息**：显示文件数、文件夹数、总计数量及跳过的目录数
- **导出功能**：将结果导出为 `.txt` 文本文件
- **复制功能**：一键复制结果到剪贴板（GUI 模式）
- **异步扫描**：GUI 模式下扫描在后台线程执行，界面不会卡顿
- **安全限制**：最大递归深度 500 层，防止无限递归；自动处理权限不足等异常

## 使用方法

### 命令行模式

```bash
python file-structure-tool_文件结构工具.py <路径> [选项]
```

#### 参数说明

| 参数 | 说明 |
|------|------|
| `<路径>` | 要扫描的文件夹路径（不填则启动 GUI 版本） |

#### 选项说明

| 选项 | 说明 |
|------|------|
| `-o, --output <路径>` | 导出到文件 |
| `-s, --style <数字>` | 路径样式：`0`=文件夹名开头，`1`=点开头，`2`=无开头，`3`=绝对路径（默认：0） |
| `-t, --tree` | 使用树形结构输出 |
| `-i, --indent <字符>` | 树形结构缩进字符（默认：空格） |
| `-l, --length <数字>` | 树形结构缩进长度（默认：2） |

#### 使用示例

```bash
# 扫描 ./assets 目录，以路径样式输出到终端
python file-structure-tool_文件结构工具.py ./assets

# 扫描并导出到文件
python file-structure-tool_文件结构工具.py ./assets -o structure.txt

# 使用点前缀样式并导出
python file-structure-tool_文件结构工具.py ./assets -s 1 -o output.txt

# 使用树形结构输出，缩进字符为"-"，缩进长度为1
python file-structure-tool_文件结构工具.py ./assets -t -i "-" -l 1

# 不指定路径，启动 GUI 图形界面
python file-structure-tool_文件结构工具.py
```

### GUI 图形界面模式

直接运行脚本不传参数即可启动图形界面：

```bash
python file-structure-tool_文件结构工具.py
```

#### GUI 操作说明

1. **选择文件夹**：点击左上角「选择文件夹」链接，在弹出的对话框中选择要扫描的目录
2. **切换输出样式**：在「样式」区域选择「路径」或「树形」
   - 路径模式下可设置前缀：文件夹 / 点 / 无 / 绝对
   - 树形模式下可设置缩进字符（空格、`-`、`|`、`.`）和缩进长度
3. **复制结果**：点击「复制」将当前显示内容复制到剪贴板
4. **导出文件**：点击「导出」将结果保存为 `.txt` 文件
5. **复制路径**：点击路径栏右侧的「复制路径」复制当前扫描目录的完整路径
6. **右键菜单**：在文本区域和输入框上右键可使用复制、全选、粘贴、剪切、清空等操作

#### GUI 界面说明

- 顶部第一行：选择文件夹、复制、导出按钮，右侧显示统计信息（文件数 / 文件夹数 / 总计 / 跳过数）
- 顶部第二行：输出样式与格式选项（根据所选样式动态显示对应选项）
- 顶部第三行：当前扫描路径显示
- 主区域：结果展示文本框，支持水平和垂直滚动

## 输出格式示例

### 路径样式（style=0，文件夹名开头）

```
assets/
assets/images/
assets/images/logo.png
assets/style.css
```

### 路径样式（style=1，点开头）

```
./images/
./images/logo.png
./style.css
```

### 树形样式

```
assets/
  images/
    logo.png
  style.css
```

## 依赖说明

- **Python 3**：核心运行环境
- **tkinter**：GUI 模式所需（Python 标准库，通常已内置；部分 Linux 发行版需单独安装，如 `sudo apt install python3-tk`）

若 tkinter 不可用，仍可正常使用命令行模式。
